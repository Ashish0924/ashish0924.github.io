- .NET / C#
- SQL / SQL Server
- Microsoft Azure
- AWS
- Azure DevOps
- CI/CD
- PowerShell / Python
- IIS / Windows Server
- Infrastructure automation
- Monitoring / production support
- AI-assisted development

## Run locally

Open `index.html` in a browser, or use any static web server.

For example:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Before publishing

1. Replace the three `#` project links in `index.html` with your actual GitHub repositories.
2. Add a professional profile photo if desired.
3. Add project screenshots/architecture diagrams when the projects are completed.
4. Review all experience claims and adjust wording to match your actual responsibilities.

## Deployment

This static site can be deployed to GitHub Pages, Azure Static Web Apps, AWS S3/CloudFront, Netlify, or another static hosting service.
